# ExerciseOfClasification
The objective was to develop and evaluate a supervised learning (classification) model capable of accurately predicting whether a lesion is benign or malignant based on its physical attributes, with a focus on the correct detection of malignant cases in the context of breast cancer.

## How to View the Google Colab File

The `.ipynb` file can be viewed in two different ways:

**1. Open the Google Colab link directly**

- Open the provided Google Colab link.
- Sign in with a Google account if necessary.
- The file will open in Google Colab, where you can review the code, explanations, and results.
- To run the code, click **Connect** and then execute the corresponding cells.

**2. Open the downloaded file**

- Download the `.ipynb` file to your computer.
- Go to [Google Colab](https://colab.research.google.com/).
- Select **File → Upload notebook**.
- Find and select the downloaded file.
- Once uploaded, you can view the notebook and run the code.

**Note:** To run the notebook correctly, you may need to install or import the required libraries and upload the corresponding data files.
